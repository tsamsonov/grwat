# Plot interannual hydrograph variable changes

This function plots the hydrograph separation variables produced by
[`gr_summarize()`](gr_summarize.md). Different background fill colors
and line types are used to differentiate seasons and variable types.

## Usage

``` r
gr_plot_vars(
  df,
  ...,
  tests = NULL,
  exclude = NULL,
  smooth = TRUE,
  layout = as.matrix(1),
  pagebreak = FALSE,
  print = TRUE
)
```

## Arguments

- df:

  `data.frame` of hydrograph and meteorological variables produced by
  [`gr_summarize()`](gr_summarize.md).

- ...:

  Quoted sequence of variable names.

- tests:

  `list` of tests for the same variables (generated by
  [`gr_test_vars()`](gr_test_vars.md) function). If tests are specified,
  then they are added to the plot.

- exclude:

  Integer vector of years to be excluded from plotting.

- smooth:

  Logical. If `TRUE` then local smoothing regression is plotted.
  Defaults to `TRUE`.

- layout:

  `matrix` that encodes the order of plotting.

- pagebreak:

  Logical. Whether to break page between plots
  ([`gr_report()`](gr_report.md)). Defaults to `FALSE`.

- print:

  Boolean. Print plot? Defaults to `TRUE`. Use `FALSE` if you want to
  tweak the plot aesthetics before plotting.

## Value

`list` of `ggplot2` objects, one for each variable, representing its
interannual changes
