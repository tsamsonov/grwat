# Plot change year density

The function extracts change years from results of
[`gr_test_vars()`](gr_test_vars.md) and plots their probability density.
Since for every variable the change year is individual, this procedure
allows finding the one most probable year, which is the mode of the
distribution. This year is highlighted by the line and labeled on the
plot.

## Usage

``` r
gr_plot_tests(tests, type = "year", print = TRUE)
```

## Arguments

- tests:

  `list` of tests generated by [`gr_test_vars()`](gr_test_vars.md).

- type:

  Character string type of the plot. Currently only `'year'` is
  supported, which means that the distribution density of the change
  year detected by Pettitt test is visualized. Ignored until other types
  are implemented.

- print:

  Boolean. Print plot? Defaults to `TRUE`. Use `FALSE` if you want to
  tweak the plot aesthetics before plotting.

## Value

`ggplot2` object representing the selected type of the tested variable

## Examples

